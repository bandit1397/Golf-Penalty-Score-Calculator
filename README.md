# ⛳ 스마트 골프 스코어 (Golf Penalty & Score Calculator)

골프장에서 휴대폰으로 쓰는 **규칙 기반 타수·벌타 자동 계산 웹앱**입니다.
샷마다 버튼 한 번, 문제가 생기면 **⚠ 상황 발생**에서 질문에 답하면 벌타, **다음 몇 타째인지**, **어디서 쳐야 하는지**를 알려 줍니다.

**바로 사용:** https://bandit1397.github.io/Golf-Penalty-Score-Calculator/
→ 휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 실행되고, 인터넷이 끊겨도 동작합니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 큰 버튼 입력 | 샷 +1, 퍼트 +1, 홀아웃, 되돌리기, 최종 타수 직접 입력 |
| 상황별 규칙 판단 | 47개 상황 — OB, 분실구, 잠정구, 빨간/노란 페널티구역, 언플레이어블(일반·벙커), 카트도로·수리지·박힌 공 등 무벌타 구제, 공이 움직임, 그린 위 상황, 잘못된 공·잘못된 장소 등 일반 페널티 |
| 잠정구 계산 | 원구/잠정구 타수를 따로 계산하고 "원구 찾으면 n타째 / 잠정구로 계속하면 m타째"를 동시에 표시. 원구를 찾으면 잠정구 타수 자동 취소 |
| 동반자 함께 기록 | 최대 5명. 위쪽 이름 버튼으로 사람을 바꿔 가며 샷별로 기록하거나, 홀이 끝난 뒤 **전원 타수 한 번에 입력**. 순위표와 전원 스코어카드, 개인별 상세 |
| 골프장 로컬룰 | OB 특설티·해저드 특설티(벌타 수 설정), E-5, 드롭존, 반대편 구제, 프리퍼드 라이 — 켜진 것만 선택 가능 |
| 친선 라운드 | OK(컨시드), 멀리건, 기브업(양파), 일파만파, 더블파 상한 — 기록에 '비공식' 표시 |
| 스코어카드 | 전반/후반/합계, 버디·보기 표시, 벌타·퍼트 합계, 결과 공유 |
| 자동 저장 | 휴대폰 안에 자동 저장, 지난 라운드 기록, 골프장 설정 저장, 백업/복원 |
| 현장 편의 | 화면 꺼짐 방지, 진동, 음성 안내, 음성 명령("티샷 오비", "잠정구", "원구 찾았어", "홀아웃"), 햇빛 모드·다크 모드, 큰 글씨, 10번 홀 시작 |

## 계산 원칙

- **스코어 = 인정되는 실제 스트로크 + 벌타**
- 홀마다 숫자 하나가 아니라 **사건 기록**(샷, 벌타, 잠정구, 정리…)을 저장하고, 점수는 매번 처음부터 다시 계산합니다. 그래서 기록을 고치거나 되돌려도 다음 타순과 18홀 합계가 항상 맞습니다.
- 공식 규칙 / 로컬룰 / 친선 처리를 구분해서 홀과 라운드에 표시합니다.
- 기준: R&A·USGA 골프 규칙 2023년판. 공식 대회에서는 위원회 판정이 우선합니다.

## 구조

```
index.html            화면 틀
css/style.css         모바일 스타일 (라이트/다크/햇빛 모드)
js/engine.js          스코어 엔진 — 사건 기록 → 타수·벌타·다음 타순 (순수 함수)
js/rules.js           규칙 데이터 — 상황 → 질문 → 처리(벌타·위치·규칙 근거)
js/app.js             화면·저장·조작
js/voice.js           음성 명령/안내 (지원 브라우저만)
sw.js                 오프라인 캐시
tests/                엔진·규칙 자동 테스트
```

빌드 과정이 없는 순수 HTML/JS라 GitHub Pages에 그대로 올라갑니다.

## 개발

```bash
npm test        # 자동 테스트 (Node 20+)
npm start       # http://localhost:8080 에서 실행
```

파일을 바꾼 뒤 배포할 때는 `sw.js`의 `VERSION`을 올려 주세요.
규칙/상황을 추가하려면 `js/rules.js`의 `CATEGORIES`에 항목을 넣으면 화면과 규칙 안내 탭에 자동으로 나타납니다.
